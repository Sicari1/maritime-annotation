# Maritime Accident Relevance Annotation

A browser-based human-annotation tool used in the evaluation of our IEEE CASE 2026 paper,
**"Multi-Field Hybrid Retrieval-Augmented Generation for Maritime Accident Root Cause Analysis"**
(SeongJin Kim, Sungil Kim — UNIST).

The retrieval system ranks maritime accident cases with a metadata-based proxy score (**RelScore**).
This tool collects human relevance judgments so we can measure how well that proxy aligns with expert
assessment: annotators take the role of a maritime accident investigator and rate each retrieved case
on a 1–5 relevance scale, with optional notes.

## Use

Open `index.html` in any modern browser — no server or install required. Ratings are entered per case
and can be exported for analysis.
