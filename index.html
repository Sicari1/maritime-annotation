🔎 What is this annotation for?

Our paper presents a retrieval system for maritime accident root-cause analysis. A reviewer asked: "Does a high proxy score actually mean the retrieved case is useful for diagnosis?" To answer this, we need human judgments of case usefulness to compare against our automated proxy scores. Cases you rate highly should match the cases our system ranks as most relevant — if they do, the proxy is validated.

🔍 Query Accident (Unknown Cause)

A target incident whose cause is not yet known. You will see only the situation summary — the cause is hidden.

📄 Candidate Precedent (Known Cause)

A past case retrieved by the system. You will see both the situation summary and the official adjudicated cause.

🧑 Your role: think like a maritime accident investigator

"I know only the situation of the first (query) accident.
If I read about how the second (candidate) accident unfolded and what caused it,
would it give me a useful clue for inferring the cause of the first accident?"

5 = perfect clue (same mechanism, would directly guide diagnosis)  |  1 = misleading (only superficially similar, different root cause, would confuse more than help)

📚 Detailed Scoring Rubric (click to expand) ▼

No domain expertise required — judge based only on what is written. Check these three points mentally:

  • (Type) Is the accident type the same or similar? (e.g., both collisions / both groundings)
  • (Context) Do conditions overlap? (weather, vessel type, time of day, watch/navigation situation)
  • (Utility) Does the candidate's cause narrative give a meaningful hint for inferring the query's cause?
ScoreCriterion
5All three apply. Reading this precedent would give a near-perfect clue for diagnosing the query accident.
4Two of three apply, especially Utility. A solid, useful reference.
3Two apply but Utility is weak, or only one applies strongly.
2Only one applies superficially. Weak reference value.
1None apply. Only surface similarity; different root cause. Would mislead more than help.

※ When in doubt, choose 3. There are no wrong answers — go with your instinct.
